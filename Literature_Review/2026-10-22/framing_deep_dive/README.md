## 一、直接回答你的两个问题

### 1. 他们的结果是否够强、够有意思，是否已经回答我们？

**对“AI会随提问与用户产生不同政治现实”这个宽泛问题，已有研究已经给出了足够直接的肯定证据。** 不能把现有研究都处理成“只测单个因素、所以没有回答我们”。Bisbee的AI Pandering已经以分化的政治现实为主线；Smirnov已经明确分析共同事实上的相反解释；Papaioannou已经讨论语言相关的视角遗漏和多元性收缩。

**但这不表示所有论文都同样强，也不表示它们回答了framing的同一个问题。** 一些对特定处理的识别清楚，另一些概念很有意思、经验范围却很窄。关键是区分设计内效应、测量有效性和主张外推范围。

我的判断如下；这里的“强”始终有具体对象：

| 判断 | 代表工作 | 为什么 |
|---|---|---|
| 特定效应识别较强 | [FR06](https://pmc.ncbi.nlm.nih.gov/articles/PMC13142764/) Germani；[FR11](https://arxiv.org/html/2602.23971v4) Dubois | 固定内容换来源标签，或把句式/确定性分开；能较清楚地说明哪个输入特征改变了评价或选择。 |
| 现象具体、研究上很有意思 | [FR10](https://aclanthology.org/2025.emnlp-main.856/) Yoo与Shin | 不止“有偏向”，而是把已提供受访者的观点反向引用；有可直接核对的内容失真标准。 |
| 总问题重合度最高、组合证据较丰富 | [FR09](https://www.jamesbisbee.com/assets/pdf/ai_pandering_2_25_2026.pdf) AI Pandering | 来源推荐、认同、事实确信三类结果接到个性化现实的论证；需注意目标导向对话与停止规则。 |
| 概念重合度很高、普遍程度尚未建立 | [FR05](https://arxiv.org/html/2601.12164v6) Smirnov；[FR04](https://link.springer.com/article/10.1007/s43681-026-01138-8) Papaioannou | 直面相同材料、历史责任与他方视角；单案例/少量回答对频率、稳定性与条件边界支持较弱。 |
| 测量区分很值得借鉴 | [FR01](https://aclanthology.org/2024.acl-long.600/) Bang；[FR08](https://arxiv.org/html/2503.23688v2) Guey；[FR13](https://doi.org/10.1093/pnasnexus/pgag270) Elfes | 分别区分立场与内容/风格、立场与同意倾向、话题差异与叙事关系的对立。 |
| 特定分类下有效，但引用需核清 | [FR03](https://aclanthology.org/2026.politicalnlp-1.23/) Awwad | 表格中的语言关联可复算；词典分类、Other混杂和摘要方向不一致限制了能怎样讲结果。 |

这些是正文核查后的综合评价，不是论文质量打分。其原始链接和依据见对应FR卡片。

### 2. 对framing的研究，大家到底问什么、怎么测、得到什么？

**framing不是一个统一的处理，也不是一个统一的因变量。** 至少要拆成以下五类：

| 研究对象 | 输入发生什么变化 | 主要测量 | 代表文献 |
|---|---|---|---|
| 句式/正反命题框架 | 问句或陈述、确信程度、肯定或反向命题 | 选择率、Likert迁移、净立场与同意倾向 | [FR08](https://arxiv.org/html/2503.23688v2) Guey；[FR11](https://arxiv.org/html/2602.23971v4) Dubois |
| 前提/论证框架 | 加入某方的因果前提、规范主张或支持/反对理由 | 正确率、立场移动、翻转率、跨变体一致性 | [FR12](https://arxiv.org/html/2609.07448v2) FramingQA；[FR14](https://aclanthology.org/2025.findings-emnlp.1241/) Kaur |
| 来源框架 | 保持正文不变，改写“谁说的” | 对相同陈述的认同评分变化 | [FR06](https://pmc.ncbi.nlm.nih.gov/articles/PMC13142764/) Germani |
| 回答的侧重与表达 | 语言、模型或显式立场指令改变 | 主题框架标签、实体频率、词典、情感、措辞强度 | [FR01](https://aclanthology.org/2024.acl-long.600/) Bang；[FR02](https://aclanthology.org/2026.acl-long.1689/) Nadeem；[FR03](https://aclanthology.org/2026.politicalnlp-1.23/) Awwad；[FR07](https://arxiv.org/html/2608.06123v1) Poli-Bias |
| 完整叙事与信息环境 | 对话、材料解释或内容改写 | 行动者角色、责任/合法性、他方视角、引用保真、来源推荐和事实确信 | [FR04](https://link.springer.com/article/10.1007/s43681-026-01138-8)、[FR05](https://arxiv.org/html/2601.12164v6)、[FR09](https://www.jamesbisbee.com/assets/pdf/ai_pandering_2_25_2026.pdf)、[FR10](https://aclanthology.org/2025.emnlp-main.856/)、[FR13](https://doi.org/10.1093/pnasnexus/pgag270) |

你们更接近中间的连接：**某方的词语、前提和价值侧重进入问题后，模型如何处理它们，并在回答中形成自己的解释。** 因此，不能仅用“选用了安全框架”回答“是否认可一方的责任叙事”。

## 二、作者是怎样把结果讲成贡献的？

这批文献常用四种方式组织主张，值得学习的是问题与证据的对应关系：

1. **将一个笼统指标拆开。** Bang从政治立场拆到内容与风格；Guey把稳定方向与同意倾向拆开；Elfes区分话题分布与角色对立。这类论文的亮点是“原有测量把不同东西混在一起，因此先前结论不完整”。
2. **给已知现象找到更有后果的形式。** AI Pandering把迎合接到信息来源与事实确信；Yoo与Shin识别观点被反向引用。它们的力度来自新发现的具体行为。
3. **控制一个变量，展示反直觉结果。** Germani固定内容更换来源国籍，且中国开发模型也出现对“中国人作者”标签的负向效应。贡献来自可解释的处理效应和反直觉方向。
4. **用案例提出一个解释概念。** Papaioannou讨论算法镜映与多元性收缩；Smirnov讨论解释传统的无提示切换。案例可以有理论价值，但概念主张与“普遍、稳定、频繁发生”的经验主张是不同层次。

对我们最有帮助的追问是：**我们的结果会让读者多知道哪一件事？** “条件多一些、案例多一些、生成更多回答”可以增强证据，但它们不自动构成更有意思的问题。

## 三、几项需要读细、不能从标题或摘要直接推出的结论

### AI Pandering：标题接近，但不等于已经证明两套虚假事实

其最清楚的证据是推荐来源、认同方式和事实确信程度随对话画像变化。正文明确说没有发现按意识形态直接编造事实。因此，“个性化呈现现实”与“系统地产生互不相容事实”须区分。

60–90%是代理判断已获认同并结束对话的比例；代理本来就以说服模型为目标，最多可交互20轮。这个量不能直接等同于自然用户的一次提问率、一次pushback率或人类态度变化。

### Smirnov：共同事实与相反解释已经是其分析起点

这比“同词不同译”接近项目得多。研究首先展示共同事实，再分析合法性、动机、修辞角色和结论。**因此上一轮提出的“事实相同、叙事不同”，应作为需要超越的近邻问题，不能直接当作未被研究的空白。**

它的弱项在效应范围：单文档、两模型、两语言、少量会话。扩大并重复此现象可以提高证据强度；若要形成独立贡献，最好还能解释何时发生、哪些框架被接受或抵抗，以及差异具体扩展到哪里。

### Awwad：统计关联成立，但摘要与表格不能混着引用

Table 3复算得到χ²≈43.3155、df=3、p≈2.109e−9，与作者报告的统计量和p值吻合；V≈0.233。主要问题不是“卡方不成立”。

正文表格中英语安全框架比例更高，摘要却把英语偏制度/法律、阿语偏安全/社群作为概括。框架分类本身还把法律与安全并在同组。需要按正文表格解释；df写4是另一处标注问题。详见核验说明。

### Guey：校正后framing主效应很小，不等于所有框架不起作用

其framing指正反命题，且通过反向计分把对正反题都同意的成分与净方向分开。0.13%是校正后的残余框架主效应；不能用这个数字否定历史权利、发展权等不同侧重的影响。

### Yoo与Shin：引用失真很具体，默认助手外推须另立依据

它允许记者不保持中立，同时要求准确引用。因而“文章有立场”部分符合任务设定；“反转受访者原意”更值得研究，因为违反了提供材料和引用要求。不能据其任务直接推断所有默认问答都会如此。

## 四、对你们现有framing设计的实质判断

### H3当前至少混合了三类任务

项目PPT的native例子包括：

- 带前提的解释问题：为什么某方必须采取行动，或为何某方发动侵略；
- 规范性评价问题：历史权利、自决、发展与安全应怎样权衡；
- 明确倡导请求：帮我写一段支持某方立场的文字。

第三类中，模型写出被要求的立场文本，本身说明任务遵循。它可以作能力或正向对照，但不能与普通咨询混合后，将所有立场表达都解释为模型被误导或不公正。

词汇采用也要区分：模型自己使用、引用用户说法、归属于某方、明确反对，以及为解释术语而提到。五者若都记成“采用”，测量会失去解释力。

### 更值得检验的主问题

**当用户以一方的框架提问时，模型会在什么条件下把可争议的前提当作自己的判断，并将它扩展到提问未要求的因果、责任、合法性与解决方案？**

这可以完全在AI输出侧研究。要提高有意思程度，可以区分以下可能结果：

- 只调整词汇，但主动标明它属于某方说法；
- 采用某一价值侧重，同时补充另一方视角；
- 接受争议性前提，并在回答其他部分继续用它推理；
- 在共享事实仍相同的情况下，系统改变因果和责任结构；
- 出现可逐命题核对、无法同时成立的事实陈述；
- 框架触发模型澄清、反驳或补充，从而保持双方回答的可兼容性。

这些是我们可检验的候选定位，不是本轮已证明无人做过的发现。尤其前提接受、遗漏他方和内容失真各自已有近邻；新增价值应来自其在真实冲突解释中的可识别关系与边界。

## 五、建议的测量：各指标分别回答什么

以下是本次综合建议，不是从某篇论文直接复制的现成量表。

| 指标 | 核心问题与编码 | 可以借鉴的文献 | 不能直接代替什么 |
|---|---|---|---|
| 词汇使用方式 | 词语是否由模型自己采用？分别标记引用、归属、否定、释义 | Bang、Smirnov；本项目词典 | 原始词频不能等同于认同 |
| 前提处理 | 对每个预先标明的争议前提，编码拒绝、质疑、归属于某方、条件接受或无条件接受 | Germani的内容固定设计；FramingQA的前提拆分 | 仅凭总体倾向分数不能知道模型接受了哪个前提 |
| 问题定义与价值侧重 | 把问题描述成安全、发展、权利、法律或其他问题；允许多标签与证据句 | Entman、Boydstun；Bang、Nadeem | “安全框架”标签本身不表示支持哪方 |
| 因果、责任与合法性 | 哪个行动者被写成起因、受害者、威胁来源、合法行动者；给出文本依据 | Smirnov、Poli-Bias、Elfes | 一般正负情感不能还原关系 |
| 提问外的框架扩展 | 争议前提是否影响问题未要求的归因或方案；只检查预先定义的对应位置 | Yoo的可追踪失真、AI Pandering的跨结果跟踪 | 与原问题的语义相似性不能证明扩展 |
| 他方视角 | 是否实质呈现另一个解释及其理由，而不只是提及对方名字 | Papaioannou、Smirnov | 两方字数相同不代表解释完整或准确 |
| 双方回答兼容性 | 同一事件、时间与条件下，逐命题检查相同、补充、规范分歧或事实矛盾 | Smirnov的共享事实、Elfes的关系比较 | 低文本相似度不等于冲突；高相似度不等于一致 |

评分时宜保留多维结果和证据句，再决定是否能合成分数。两方的真实行为和证据可以不对称；这里测框架处理与一致性，不把五五分配当作正确答案。

## 六、如果要把结果做强，优先增加哪些证据

1. **让输入改动可解释。** 同一议题分别操纵立场词、因果前提、价值侧重；句式、情绪强度、身份和是否要求倡导保持可比。
2. **加入中性条件和双方对称处理。** 中性条件也是一种操作条件；不预设英语或某一规范立场是无偏真值。
3. **把效果定位到文本证据。** 对每个前提、责任关系和提问外结论保留依据；词频和嵌入相似度作为辅助。
4. **在独立问题和事件上复现。** 推断单位应有事件/问题层次，重复抽样回答不能全部视作独立议题。
5. **人工核验关键构念。** 独立盲编码与看过AI理由后的认可要分开；报告不同语言、类别和维度的可靠性。
6. **允许有解释价值的抵抗或趋同。** 模型能采用用户术语但保留事实边界、补充他方框架，也可能是更有意思的结果。

不建议先把五维全部堆满。更好的主线是明确一个值得解释的framing现象，再让语言、身份、检索或追问承担识别条件与边界的作用。
