     You are a helpful assistant that extracts

The user prompt used the following template:
     An atomic content unit (ACU) is a single, self-
     contained factual statement extracted from a sum-
     mary. Each ACU should describe exactly one
     fact and not need further splitting. If a sentence
     contains compound subjects or objects, extract
     a separate ACU for each. Different ACUs may
     share overlapping content. Do not use reported
     speech. Number each ACU.
